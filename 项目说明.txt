一、这是什么
----------------------------------------------------------
一个部署在 GitHub Pages 的静态网站，目前共 2 个页面：
  1. index.html  课表速查助手（班级课表 / 个人课表 / 教师通讯录 / 统计）
  2. editor.html 代课管理助手（可视化改课表 / 代课通知工具 / 通讯录 / 批量导入导出）
所有功能共用同一份数据文件，改一处，处处同步。

★ 旧的 import.html 和 admin.html 已删除，目前只有上述两个页面。

二、网址（老师用手机/电脑可直接打开，无需代理）
----------------------------------------------------------
  课表速查助手   https://ddlz43.github.io/-V12/
  代课管理助手   https://ddlz43.github.io/-V12/editor.html

三、数据在哪改（唯一数据文件）
----------------------------------------------------------
  文件：项目根目录下的  js/data.json
  内容：scheduleData（70 个班级的课表）+ contactsData（227 位教师含电话）
  ★ 关键：所有页面都从这一个文件读数据，改这一个文件 = 全部同步。

四、页面导航结构（底部导航）
----------------------------------------------------------
  index.html：   班级课表 | 个人课表 | 通讯录 | 统计
  editor.html：  修改 | 代课 | 通讯录 | 导出

五、平时改课表怎么做（推荐用编辑器）
----------------------------------------------------------
  1. 打开  editor.html（代课管理助手）
  2. 选班级 → 点格子改课程 / 教师；下面可改教师电话
  3. 点【保存并导出】→ 下载新 data.json，替换本地 js/data.json
  4. 双击「上传.bat」一键上传到 GitHub
  5. 等 1~2 分钟，强刷网页（Ctrl+F5）即可看到最新数据

六、每学期整体换新课表怎么做
----------------------------------------------------------
  用 editor.html「导出」面板的导入/批量功能，生成新 data.json，
  替换本地 js/data.json，再走「上传.bat」发布。
  ★ 原教师电话会自动按姓名合并保留，不会丢。

七、上传 / 发布（什么时候需要）
----------------------------------------------------------
  - 只有"改完数据要上线"时才需要上传。
  - 方法：双击项目里的「上传.bat」，它自动 add + commit + push。
  - 上传需要能连上 GitHub 的网络（国内不稳定，可开代理或重试）。
  - 网站本身（老师打开看）不需要代理。

八、常见问题
----------------------------------------------------------
  Q：打开网页是空的 / 显示的旧的课表？
  A：基本是浏览器缓存。强制刷新（Ctrl+F5）或换无痕窗口；
     或访问网址后加 ?v=数字 绕过缓存。
  Q：上传失败、连不上 GitHub？
  A：网络问题，开代理或过会儿重试，多试几次即可。
  Q：电脑上 .git 文件夹显示"只读"？
  A：正常现象，Git 自己的保护机制，不用管它，别去取消只读。
