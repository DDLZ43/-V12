                白沙小学 · 课表代课系统 —— 项目说明

一、这是什么
--------------------------------------------------------------------
一个部署在 GitHub Pages 的纯静态网站，手机/电脑浏览器直接访问，
无需安装。目前包含 2 个页面：

  1. index.html   课表速查助手
     - 班级课表：选班级看整个班一周课表（含课程、教师）
     - 个人课表：按教师姓名查某位老师一周教哪些班哪些节
     - 教师通讯录：按姓名/电话/拼音首字母搜索，显示号码
     - 统计：课程分布汇总等

  2. editor.html  代课管理助手（管理员用）
     - 代课：教师请假登记 → 勾选需代课节次 → 生成通知一键复制发微信
             → 生成 Excel 代课记录（累积池）
     - 修改：可视化改课表（选班级→点格子改课程/教师），改完导出 data.json
             → 教师通讯录（可改号码，支持搜索、查看全部）
     - 导入：原始课表转换工具（从 Excel 粘贴 → 生成 data.json，
             自动合并保留旧电话）

打开 editor.html 默认进入「代课」页面；
地址加 #修改 可直达「修改」，#代课 直达「代课」。

所有功能共用同一份数据文件，改一处，处处同步。


二、核心数据文件
--------------------------------------------------------------------
  js/data.json —— 全站唯一数据源，含：
    {
      "scheduleData": {           // 课表
        "一1": {                  // 班级名（汉字年级+数字班号）
          "星期一": {             // 星期
            "1": {                // 节次（1-6）
              "course": "语文",   // 课程名
              "teacher": "王丽君",// 教师名
              "room": "-"         // 教室/备注，默认"-"
            }
          }
        },
        "一2": {...}, ...         // 共约 70 个班（一1-一13、二1-二12、三1-...等）
      },
      "contactsData": [           // 教师通讯录
        { "name": "张三", "phone": "138...", "note": "" }
      ],
      "periods": [1,2,3,4,5,6],   // 每天 6 节
      "days": ["星期一",...]      // 周一至周五
    }


三、页面/脚本/样式
--------------------------------------------------------------------
  index.html       课表速查页面
  editor.html      代课管理页面（默认面板=代课，底部导航：代课/修改/导入）
  css/style.css    全局样式
  js/app.js         index.html 逻辑（班级/个人/通讯录/统计）
  js/data-loader.js 数据加载（把 data.json 注入 window.scheduleData / contactsData）
  js/daike.js       代课工具逻辑（搜索联想、勾选、累积、通知、复制、Excel）
  lib/xlsx.full.min.js  SheetJS，用于导出 Excel


四、日常用法（管理员）
--------------------------------------------------------------------
【改课表】
  editor.html → 选"修改" → 选班级 → 点格子直接改课程/教师
  → 点"保存并导出 data.json"下载文件
  → 用下载文件替换 js/data.json

【更新上线三步走】
  1. 用新下载的 data.json 替换 本地 js/ 下的 data.json
  2. 双击项目里的「上传.bat」提交推送到 GitHub
  3. 等 1-2 分钟，网页强刷（Ctrl+F5）即可看到更新

【批量导入新课表/新通讯录】
  editor.html → 选"导入"
  → 从 Excel 选中整张课表（含第1行星期、第2行节次、各班级课程/教师行）
  → Ctrl+C 复制，粘贴到文本框
  → 点"生成 data.json"，预览确认后下载
  → 替换 js/data.json 并按上面三步上线

六、重要约定与注意事项
--------------------------------------------------------------------
  ◆ data.json 是 UTF-8 编码的中文数据，替换时务必保持编码一致，
    否则网页可能出现乱码。
  ◆ 班级命名固定用「汉字年级 + 数字」，如 一1、二10、三13，不要改成阿拉伯
    数字年级（如 1年级1班），否则排序和识别会出错。
  ◆ 每天固定 6 节（个别有第7节的需另做处理）。
  ◆ 「生成通知一键复制」在手机端已做兼容（Async Clipboard / execCommand /
    手动复制三级降级），保证各种浏览器都能复制到微信。
  ◆ 手机端通讯录、代课功能样式已适配，宽度与底部导航对齐。
