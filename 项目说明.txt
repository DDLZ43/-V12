一、这是什么
----------------------------------------------------------
一个部署在 GitHub Pages 的静态网站，包含：
  1. 课表系统（查班级课表 / 教师课表 / 教师通讯录）
  2. 代课通知工具（需口令；但从课表编辑器可免口令快速进入）
  3. 管理后台（数据统计）
  4. 课表调整（可视化编辑课表）
  5. 原始课表导入（Excel 转换工具，生成 data.json）
所有功能共用同一份数据文件，改一处，处处同步。

三、数据在哪改（唯一数据文件）
----------------------------------------------------------
  文件：项目根目录下的  js/data.json
  内容：scheduleData（70 个班级的课表）+ contactsData（227 位教师含电话）
  ★ 关键：所有页面都从这一个文件读数据，改这一个文件 = 全部同步。

四、页面导航结构（顶部按钮）
----------------------------------------------------------
  课表调整 editor.html：    返回代课 | 查看课表 | 课表调整 | 原始课表导入
  原始课表导入 import.html：返回代课 | 查看课表 | 课表调整 | 原始课表导入
  ★ 点击"返回代课"会带 ?auto=1 参数跳往 daike.html，可免口令直接进入，
    且首屏不会闪现口令锁。

五、平时改课表怎么做（推荐用编辑器）
----------------------------------------------------------
  1. 打开  editor.html（课表调整）
  2. 选班级 → 点格子改课程 / 教师；下面可改教师电话
  3. 点【保存并导出 data.json】→ 下载新文件
  4. 用新文件替换本地  js/data.json
  5. 双击「上传.bat」一键上传到 GitHub
  6. 等 1~2 分钟，强刷网页（Ctrl+F5）即可看到最新数据

六、每学期整体换新课表怎么做
----------------------------------------------------------
  1. 打开  import.html（原始课表导入，免口令；旧版在 admin.html，现已移除）
  2. 从 Excel 复制整张课表，粘贴、生成
  3. 下载 data.json，替换本地 js/data.json，再走"上传.bat"发布
  ★ 原教师电话会自动按姓名合并保留，不会丢。
  ★ 管理后台 admin.html 仅保留"数据管理"统计区，已不含转换工具。

七、上传 / 发布（什么时候需要）
----------------------------------------------------------
  - 只有"改完数据要上线"时才需要上传。
  - 方法：双击项目里的「上传.bat」，它自动 add + commit + push。
  - 上传需要能连上 GitHub 的网络（国内不稳定，可开代理或重试）。
  - 网站本身（老师打开看）不需要代理。

八、常见问题
----------------------------------------------------------
  Q：打开网页是空的 / 显示的旧的课表？
  A：基本是浏览器缓存。强制刷新（Ctrl+F5）或换无痕窗口；
     个别页面若仍显示旧版，可关闭浏览器重试，或在网址后加 ?v=数字 绕过缓存。
  Q：只有一个页面（如 admin.html）打不开，其他正常？
  A：多为浏览器缓存了旧版本。关闭浏览器重开、无痕窗口，
     或访问 admin.html?v=123 强制拉取最新内容。
  Q：上传失败、连不上 GitHub？
  A：网络问题，开代理或过会儿重试，多试几次即可。
  Q：电脑上 .git 文件夹显示"只读"？
  A：正常现象，Git 自己的保护机制，不用管它，别去取消只读。
