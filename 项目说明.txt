一、这是什么
----------------------------------------------------------
一个部署在 GitHub Pages 的静态网站，包含：
  1. 课表系统（查班级课表 / 教师课表 / 教师通讯录）
  2. 代课通知工具（需口令）
  3. 管理后台（教师请假登记等）
  4. 可视化课表编辑器
所有功能共用同一份数据文件，改一处，处处同步。
当前数据规模：70 个班级（一1 ~ 六10）、227 位教师（含电话）。

二、网址（老师用手机/电脑可直接打开，无需代理）
----------------------------------------------------------
  课表系统  https://ddlz43.github.io/-V12/
  代课系统  https://ddlz43.github.io/-V12/daike.html
  管理后台  https://ddlz43.github.io/-V12/admin.html
  课表编辑器 https://ddlz43.github.io/-V12/editor.html
  ★ 老师浏览网页不需要代理；只有"上传发布"时才需要开代理（见第六节）。

三、数据在哪改（唯一数据文件）
----------------------------------------------------------
  文件：项目根目录下的  js/data.json
  内容：scheduleData（70 个班级的课表）+ contactsData（227 位教师含电话）
  ★ 关键：所有页面都从这一个文件读数据，改这一个文件 = 全部同步。

四、平时改课表怎么做（推荐用编辑器）
----------------------------------------------------------
  1. 打开  editor.html（课表编辑器）
  2. 选班级 → 点格子改课程 / 教师；下面可改教师电话
  3. 点【保存并导出 data.json】→ 下载新文件
  4. 用新文件替换本地  js/data.json
  5. 打开 Clash（开系统代理），双击「上传.bat」一键上传到 GitHub
  6. 等 1~2 分钟，强刷网页（Ctrl+F5）即可看到最新数据

五、每学期整体换新课表怎么做
----------------------------------------------------------
  1. 打开  admin.html（管理后台的"Excel导入"功能）
  2. 从 Excel 复制整张课表，粘贴、生成
  3. 下载 data.json，替换本地 js/data.json，再走"上传.bat"发布
  ★ 原教师电话会自动按姓名合并保留，不会丢。

六、上传 / 发布（什么时候需要、怎么做）
----------------------------------------------------------
  - 只有"改完数据要上线"时才需要上传。
  - 上传路径：双击项目里的「上传.bat」，自动 add + commit + push。
  - ★ 关键：上传必须能连上 GitHub。国内直连不稳定，需打开代理软件
    （本机用 Clash，混合端口 127.0.0.1:7897）。
    ※ 上传.bat 会自动读取系统代理端口并配置给 git，
      因此只需在 Clash 里打开【系统代理】开关即可，无需手动配置。
  - 上传成功会显示 [SUCCESS] Upload ok!；失败显示 [FAIL]。
  - 网站本身（老师打开看）不需要代理。
  - ★ 上传.bat 是英文提示的纯 ASCII 脚本，安全可靠（见第九节）。

七、常见问题
----------------------------------------------------------
  Q：打开网页是空的 / 显示的旧的课表？
  A：基本是浏览器缓存。强制刷新（Ctrl+F5）或换无痕窗口。
  Q：双击上传显示 [FAIL]？
  A：八成是代理没开或没生效。确认 Clash 已开启【系统代理】后重试。
     （注意：代理检测靠系统代理开关，若提示未检测到代理请打开它）
  Q：双击上传后窗口一闪就没了 / 没反应？
  A：脚本开头会检查"有没有改动"。没有改动会提示并退出——
     请确认 data.json / index.html 等信息已保存。
  Q：电脑上 .git 文件夹显示"只读"？
  A：正常现象，Git 自己的保护机制，不用管它，别去取消只读。
  Q：页面标题（标签页/顶部）改了没变化？
  A：改了 index.html 的标题后需走上传流程发布；发布后需强刷网页。
     标签页标题在 <title>，页面顶部大标题在 .logo-text，两处是分开的。

九、上传脚本（上传.bat）说明
----------------------------------------------------------
  - 纯 ASCII / 英文提示（避免中文编码问题，保证任何 Windows 都能跑）。
  - 功能：①自动检测系统代理 ②临时配置 git 代理 ③git add + commit + push。
  - 每次上传自动提交，提交信息格式：Update data 年月日时分。
  - 若报 [FAIL]，多半是代理未生效或网络问题，开代理后重试。

十、安全注意事项（重要）
----------------------------------------------------------
  - 项目根目录不要放任何"令牌/token/密钥"文件！
    曾出现 github令牌.txt 被 git add -A 误提交，触发 GitHub 推送拦截。
    现已在 .gitignore 中排除（github令牌.txt、*.token、*.secret）。
    ★ 以后若再涉及 GitHub 登录令牌，请勿放进项目文件夹，或务必加入 .gitignore。
  - 代课口令配置在  js/daike-config.js 的 DAKE_PASSWORD（现为 905763），
    该文件会随项目上传到 GitHub（公开仓库），口令等于公开，建议定期更换。
